# TaskFlow - Daily Task & To-Do Management App

A sleek, minimalist, and responsive productivity web application designed to help individuals track their daily goals and manage tasks efficiently.

## ✨ Key Features
- **Quick Task Entry**: Add new tasks with keyboard shortcuts (`Enter`) or button clicks.
- **Status Toggling**: Mark tasks as completed or active with interactive checkboxes and strikethrough styling.
- **Task Deletion**: Easily remove obsolete tasks from the list with confirmation feedback.
- **LocalStorage Integration**: Automatic synchronization with browser storage ensures tasks remain saved across sessions.
- **Mobile-First Responsive UI**: Fast and distraction-free interface optimized for both mobile and desktop use.

## 🛠️ Technology Stack
- **HTML5**: Semantic structure
- **CSS3**: Clean minimalist styling with subtle hover states
- **JavaScript**: DOM manipulation and persistent LocalStorage state management
